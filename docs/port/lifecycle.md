# Lifecycle port (start-up / shutdown through Paper's flow)

Entry: `org.bukkit.craftbukkit.Main` (Craft, unmodified) -> `PaperBootstrap.boot` -> `Main.main(OptionSet)` (MainMixin),
which stores the options in `net.fissionmc.backend.boot.PaperStartup` and runs vanilla `Main.main(String[])` with the
vanilla arguments Paper's options imply. Every Paper hunk is an injection active only in that case (`PaperStartup.active()`
/ `MinecraftServer.options != null`), so starting `net.minecraft.server.Main` directly still runs vanilla start-up.

Infra: `loader/.../FissionLogger.kt` keeps the JVM's original stderr (the server replaces System.out/err with Paper's
SysoutCatcher, which needs Bukkit.getServer(), while classes are still transformed). `loader/.../Bootstrap.kt` initialises
MixinExtras after the transformer is installed. The dev run task starts `org.bukkit.craftbukkit.Main --nogui`
(`-Dfission.main`); jline falls back to a plain reader when stdin is not a terminal, so `--nojline` is not needed.
